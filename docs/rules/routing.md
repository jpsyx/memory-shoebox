# Routing rules

This project routes with
[TanStack Router](https://tanstack.com/router) v1 (file-based).

Routes are file-based. Add a file under `src/routes/` and the TanStack Router
Vite plugin regenerates `src/routeTree.gen.ts` automatically. Never edit
`routeTree.gen.ts` (or any `*.gen.*` file) by hand.

The dev server runs at http://localhost:5173.
