# Memory Shoebox PRD

The product record for this repository is [`docs/PRODUCT.md`](../../PRODUCT.md).

It is the PRD for this scoping run and lives at that path rather than here,
because impeccable reads `PRODUCT.md` there and will not find it anywhere else.
One product deserves one record rather than two that drift.

Everything else this run produced is in this directory:

| File                               | What it is                                                                                    |
| ---------------------------------- | --------------------------------------------------------------------------------------------- |
| [`design-spec.md`](design-spec.md) | Every surface, every state, the user flows, and the rules the mockups encode but cannot state |
| [`tech-specs/`](tech-specs)        | The schema and the API contract                                                               |
| [`plan/`](plan/README.md)          | The build order: fifteen steps, one file each, with a README that says how to execute them    |
