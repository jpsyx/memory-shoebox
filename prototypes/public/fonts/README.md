# Fonts

These three faces are self-hosted rather than loaded from a CDN, so the
prototypes render identically offline and do not call out to a third party.
Each is the `latin` subset of the variable font, taken from Google Fonts.

| File                    | Family                                                                 | Designer        | Licence                   |
| ----------------------- | ---------------------------------------------------------------------- | --------------- | ------------------------- |
| `Archivo.woff2`         | [Archivo](https://fonts.google.com/specimen/Archivo)                   | Omnibus-Type    | SIL Open Font License 1.1 |
| `ArchivoNarrow.woff2`   | [Archivo Narrow](https://fonts.google.com/specimen/Archivo+Narrow)     | Omnibus-Type    | SIL Open Font License 1.1 |
| `FamiljenGrotesk.woff2` | [Familjen Grotesk](https://fonts.google.com/specimen/Familjen+Grotesk) | Chatnoir Studio | SIL Open Font License 1.1 |

The SIL Open Font License permits bundling and redistribution, including in a
commercial or AGPL-licensed work, provided the licence notice travels with the
fonts. That is what this file is. The full licence text ships with each font's
upstream source, linked above.

These are prototype choices, not a committed type system. Whatever `DESIGN.md`
records is the decision; if the faces change, replace the files and this table
together.
